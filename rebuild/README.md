# New Scarlet Crystal implementation

This tree contains only new SwiftUI, action/adaptor protocols, signing-expiry policies, source-monitoring tools, and tests. No V-series patch script is imported or required.

The four protected engines/material systems are original native Liquid Glass, LiveContainer, SideStore, SideSign. All non-glass UI is independently redesignable. Existing app bundle IDs, provisioning and user data are compatibility boundaries.

Figma source: https://www.figma.com/design/QESg6S7oJS47PmlPpEX5w5

Integrated host app, automatic installation and real iPhone validation are **not complete**.
