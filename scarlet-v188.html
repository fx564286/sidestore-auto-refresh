버튼을 누르면 iOS의 itms-services 설치 경로가 열리고 실제 Scarlet Crystal 앱 설치를 요청해.

Scarlet Crystal V188 앱 설치 서명된 V188 IPA 확인 기존 설치 앱을 삭제하지 마. 동일한 Bundle ID 및 App Group으로 업데이트해야 앱 데이터가 유지될 수 있어.

서명·설치 조건

V188 서명본은 Apple Development 인증서와 기존 iPhone 등록 프로파일로 만들어졌어. 서명은 성공했지만 Safari OTA 배포용 Ad Hoc 서명이 아니므로 기기에서 설치가 거부될 수 있어.

설치 버튼이 앱 다운로드를 시작해도 실제 설치·실행 성공은 별도로 확인해야 해. Apple이 설치를 거부하면 개발용 서명 IPA는 페어링된 PC 또는 적합한 Ad Hoc 배포 방식으로 설치해야 해.

앱 데이터·Liquid Glass

기존 Team ID P8EZT3U5N4, Bundle ID com.kdt.livecontainer.P8EZT3U5N4, App Group은 유지했어. UI 시각적 동작과 앱 데이터 보존은 설치 후 아이폰에서 확인해야 해.

OTA 설치가 진행되지 않을 때
  1. 설정 프로파일을 추가 설치해도 개발용 IPA가 Ad Hoc 서명으로 바뀌지는 않아.
  2. PC와 아이폰의 기존 페어링을 사용해 서명 IPA로 덮어 설치할 수 있어.
  3. App Group·Keychain 상태를 확인하기 전 기존 앱을 제거하지 마.
실제 설치 대상은 GitHub에 게시된 서명 IPA야. 개인키·P12·Apple ID 비밀번호는 웹페이지로 업로드하지 않아.
