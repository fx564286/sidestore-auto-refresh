홍수정 V188 설치

Liquid Glass UI를 유지한 V188 빌드를 아이폰에서 서명·설치하는 경로야. 기존 앱과 데이터는 삭제하지 마.

① Safari 설치 포털 프로파일

설정 프로파일을 설치하면 홈 화면에 Scarlet V188 설치 페이지가 추가돼. 이 프로파일은 앱, DNS, VPN, 인증서를 설치하지 않아.

Scarlet V188 설치 포털 프로파일 받기 Safari에서 다운로드 허용 → 설정 → 프로파일 다운로드됨 → 설치.

② SideInstaller에서 원터치 설치

V188 미서명 IPA 공개 · GitHub SHA-256 확인

기존 SideInstaller가 설치되어 있다면, 다음 버튼을 탭해 IPA를 불러오고 아이폰에서 Apple ID로 서명할 수 있어.

SideInstaller로 V188 서명·설치 SideInstaller 공식 설치 사이트 원터치 링크는 SideInstaller의 sideinstaller://install?url= 기능을 사용해. 설치 전 SideInstaller가 표시하는 앱 ID·Team·프로파일을 확인해.

기존 앱 업데이트 주의: 현재 기존 P12가 새 Apple 프로비저닝 프로파일에서 승인되지 않았어. SideInstaller가 다른 Bundle ID, Team ID, App Group 또는 Keychain 권한으로 서명한다면 업데이트를 중단해. 앱을 삭제하지 마.

③ 서명 IPA 없이 Safari 단독 OTA 설치

아직 불가. Safari에서 단독으로 설치하려면 해당 기기에 배포 가능한 정식 서명 IPA와 Apple이 승인한 프로비저닝 프로파일이 필요해.

서명 IPA 확보 대기 미서명 IPA나 WebClip 프로파일만으로 iOS 앱이 설치되는 것처럼 표시하지 않아.
